05

Portability

Dual-vendor, and honest about the gaps

Labs ship as hip/ and cuda/ line-for-line counterparts, plus a triton/ path that runs on both.

  • A lockstep bundle is 64 lanes on AMD, 32 on NVIDIA — so block sizes that are multiples of 64 are the portable choice.
  • NVIDIA-only material (CuTe, CUTLASS, cuTile) is marked optional and names its AMD counterparts.

06

The rule that shaped everything

Never publish a number the repo cannot reproduce

  • Benchmark tables are omitted in favour of expected ordering and traffic ratios, which follow from the algorithm rather than the silicon.
  • Analytic tools print a banner marking output as a model, not a measurement.
  • Published figures are attributed to their paper and its conditions.
  • Hardware specs carry a source link and a retrieval date.

Module B04 · Precision

"fp8" is two different formats

CDNA 3 implements the FNUZ variants (bias 8, max 240). Hopper implements OCP (bias 7, max 448).

  • Bit pattern 0_0111_000 is 1.0 under OCP and 0.5 under FNUZ — load the wrong checkpoint and every weight is 2× too large.
  • 0x80 means NaN under FNUZ but -0.0 under OCP, so a genuinely-NaN element silently becomes a harmless zero.

Module B07 · Sharding

Pipelining does not reduce activation memory

Under 1F1B scheduling, each stage holds L/S layers but keeps S micro-batches in flight. The S cancels.

Engineers reach for pipeline parallelism as a memory fix. It is a throughput fix. Deriving why is worth more than a page of guidance.

Module C07 · Capstone

The KV cache was not the binding constraint

Sizing an LLM serving node: HBM allows a 3.56 million token KV pool, but the 30 ms latency SLO caps the scheduler at 567 thousand. Latency binds first.

Quantizing to fp8 then flips decode to compute-bound — so further KV quantization buys nothing. Knowing where an optimization stops paying is the harder judgement.
