## Layout

```
content/social/
├── README.md                 <- this file
├── HISTORY.md                <- chronological chain (update on every new pack)
└── NNN-<slug>/               <- one folder per post
    ├── linkedin.md
    ├── shorts-script.md
    ├── blog.md
    ├── snippet.<ext>
    ├── visual-brief.md
    └── (optional) visual.png / frames/
```

## Rules

1. **Every new pack** gets the next `NNN` and a new top entry in [`HISTORY.md`](HISTORY.md).
2. **Recurrent posts** must link `prev` / `next` in HISTORY (series continuity).
3. Numbers come from a **documented run** (module README or `content/<module>/long-form.md`). Re-state your GPU when publishing.
4. Packs stay editable sources — never a locked LinkedIn draft as the only copy.
