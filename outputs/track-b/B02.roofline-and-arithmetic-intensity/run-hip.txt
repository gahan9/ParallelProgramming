ridge point   I_ridge = P / B      = 27.78 FLOP/byte
  below 27.78 FLOP/byte -> memory-bound (bandwidth decides)
  above 27.78 FLOP/byte -> compute-bound (FLOP/s decides)

What this means in practice: a kernel needs to do more than 28 FLOPs for
every byte it pulls from HBM before arithmetic becomes its limit. An
elementwise add does about 0.08. That gap is why fusion pays.

Draw the chart:
  python ../tools/roofline_plot.py --peak-gflops 120725 --peak-gbps 4345 --demo-kernels

Caveat: P here is the fp32 SIMT FMA roof. Matrix cores (AMD MFMA / NVIDIA
Tensor Cores) have their own, far higher roof for fp16/bf16/fp8, and that
is the ceiling ML kernels are actually measured against. See README S6.

on the memory roof, then flattens once it hits the compute roof. GB/s does
the mirror image. The K where the two curves cross is the ridge point above.
Absolute values are hardware-specific; the shape is not.
