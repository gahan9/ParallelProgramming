------------------------------------------------------------------------------

  full run          : 64 GPU-hours
  search space      : 4 dimensions, 70% of the variance in one of them
  halving           : eta=3, 4 rungs, early-run noise 0.35
  repetitions       : 400 (seed 20260729)

  strategy             configs  full runs  distinct values
                      explored   completed  on the dim that matters
  ------------------- --------- ----------- -----------------------
  grid                       32          32                       2
  random                     32          32                      32
  successive halving        216           8                     216

  strategy             mean best   median   p10      p90
  ------------------- ---------- -------- -------- --------
  grid                     1.477    1.491    0.549    2.396
  random                   2.032    1.992    1.408    2.612
  successive halving       2.737    2.700    2.164    3.344

  How to read this
  - Grid and random spend the identical budget, but grid retries the same
    values of the dimension that matters, so it effectively samples far
    fewer distinct settings. That gap widens with --dimensions.
  - Successive halving explores far more configs for the same money by
    killing bad ones early. Its risk is --early-noise: if short runs do
    not rank configs correctly, it discards the eventual winner. Raise
    --early-noise and watch its advantage disappear.
  - p10 is the number to defend in a review: it is the outcome when the
    search gets unlucky, and it is what a one-shot experiment actually is.
