Read sweep 1 for 'theoretical occupancy barely moves, time still does' and
sweep 2 for the real occupancy cliff: every doubling of the LDS request halves
the resident blocks. Occupancy is a means (latency hiding), not the goal -
if Ghops/s stops improving while occupancy still rises, you have found the
point of diminishing returns on this GPU.
